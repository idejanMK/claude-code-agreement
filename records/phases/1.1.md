# 1.1 — Installable package

- **Milestone:** M1
- **Status:** closed 2026-11-22
- **Branch:** feature/1.1-package
- **Gate 1:** verify lines approved 2026-11-22 by the owner

## Why

Anyone (the owner on a new machine, or a stranger from GitHub) installs the whole agreement system with
one skill, starts or adopts a project with records and cost accounting working from the first session,
and can check that the install is exact.

## Scope

**Changes:** the package moves under `package/`, shaped like `~/.claude`; the missing pieces ship
(three agents, cost-html, four templates); every shipped file loses personal names and paths; the records
rules cover every record file; a new `/agreement-setup` (plan · apply · check, one Node script);
`/new-project` rewritten with an adopt mode; a `.scratch/` housekeeping rule; cost rows lose the local
folder path; the agreement's "This config is a repo" section and the README rewritten; `master` → `main`;
the owner's machine cut over to install from here.

**Does not change:** the records grammar for existing projects; hook behaviour beyond the cost-row path
and the scratch size line; anything listed as out in D7.
