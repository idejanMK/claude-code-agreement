# 2.1 — Session naming

- **Milestone:** M2
- **Status:** open since 2026-11-25
- **Branch:** feature/2.1-session-naming
- **Gate 1:** verify lines approved 2026-11-25 by the owner

## Why

Sessions are titled by a small model from the first prompt ("Go 2.2.7.2", "Cache expiry prompt hook"),
so a list of sessions across projects says little. The records already know the project, the ID and
the heading; a hook can set the title from them at no model cost.

## Scope

**Changes:** one new UserPromptSubmit hook, `session-title.js`, that on a prompt starting work (`go <id>`,
`/open-phase <id>`, `/close-phase`) sets the session title to `<ID> <heading>`; its wiring in
the settings snippet; a row in the hooks reference; one line in the agreement; the owner's machine
reinstalled.

**Does not change:** the records mod (naming works with the mod off); any other hook; the generated
title of a session that never starts work; a title the owner set by hand.

## Context

- Hooks docs (code.claude.com/docs/en/hooks, read 2026-11-25): `sessionTitle` is accepted under
  `hookSpecificOutput` by SessionStart and UserPromptSubmit, "with the same effect as `/rename`". A
  UserPromptSubmit hook with no `decision` field lets the prompt through. The input carries
  `session_title` only when the session has a custom title (set by `--name`, `/rename`, a hook or the
  SDK); a generated title is not a custom title. Nothing is said about where the title is displayed.
- A title the hook set is itself a "custom title", so `session_title` alone cannot tell the owner's
  rename from the hook's own earlier name. Hence the state file: equal to what we last set → ours,
  overwrite; different → the owner's, keep.
- Slash commands reach UserPromptSubmit hooks (the cold-resume gate already filters on them).
- Seen 2026-11-25 in a VS Code session (spike hook's captured input): `prompt` can start with an
  editor-added block (`<browser_instruction>…</browser_instruction>`) before the typed text, so a
  match anchored at the start of `prompt` misses. 2.1.2 strips such leading blocks first.
- Decision: D14.
